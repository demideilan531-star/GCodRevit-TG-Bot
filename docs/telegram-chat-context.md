# Контекст Telegram для GCodRevit Bot

## Что реализовано

- Telegram Secretary Mode передаёт Worker новые сообщения только из чатов, выбранных владельцем аккаунта.
- Worker сохраняет текст, подписи и безопасные обозначения вложений в отдельную D1-базу `gcodrevit-chat-context`.
- Mini App `/context/` показывает сохранённые чаты и выгружает последние 20, 50, 100 или 200 сообщений в Markdown.
- Markdown можно скопировать в ChatGPT/Codex или скачать и приложить к диалогу.
- Можно создать временную ссылку только для выбранного чата: она открывает актуальные последние сообщения без входа в Telegram.

## Ограничения

- Bot API не предоставляет историю сообщений до подключения Secretary Mode.
- Сами фото, видео, документы и голосовые сообщения не сохраняются.
- Телефоны контактов, координаты и Telegram `file_id` не сохраняются.
- Текст автоматически удаляется через 30 дней.
- Бот не отвечает собеседникам и не отправляет сообщения от имени владельца.

## Подключение

1. В `@BotFather` открыть `@GCodRevit_bot` → **Bot Settings** → **Secretary Mode** и включить режим.
2. В Telegram открыть **Настройки → Автоматизация чатов**, выбрать `@GCodRevit_bot` и разрешить доступ только к нужным чатам.
3. Не выдавать права на ответы, удаление сообщений, изменение профиля, истории или публикаций.
4. Написать боту `/start`. Команда обновит webhook и включит события `business_*`.
5. Отправить новое сообщение в одном из выбранных чатов.
6. Открыть Mini App кнопкой **Open App**, перейти в раздел **Контекст** и обновить список.

## Использование с GPT

- **Codex:** нажать **Скачать .md** и приложить файл к текущей задаче.
- **ChatGPT в браузере:** нажать **Копировать** и вставить текст в сообщение либо загрузить скачанный `.md`.
- **Другой агент с доступом к веб-страницам:** выбрать чат и число сообщений, нажать **Ссылка**, выбрать срок и создать ссылку. Скопировать её кнопкой рядом с адресом и передать агенту с запросом прочитать контекст.

## Временные ссылки

- Ссылка содержит право чтения: любой, кто её получил, может прочитать выбранный контекст. Не публиковать её в открытом доступе.
- Доступ ограничен одним чатом и последними 1–200 сообщениями. В интерфейсе доступны окна 20, 50, 100 и 200 сообщений.
- Это живое окно, а не снимок: новые сообщения попадают в него, изменённые обновляются, удалённые исчезают. Отдельная копия переписки не хранится.
- Срок: 1 час, 24 часа по умолчанию или 7 дней. До 20 активных ссылок на владельца.
- В окне **Ссылка** можно повторно скопировать адрес или отключить его. Удаление контекста чата отключает все ссылки на него. Блокировка владельца также прекращает доступ.
- Отзыв не удаляет копии, которые получатель уже скачал. Заголовки `no-store`, `noindex` и `no-referrer` снижают случайное распространение, но не заменяют контроль над получателями.
- API-ключи и токен Telegram в адрес не входят. URL содержит UUID и подпись HMAC-SHA256 с разделением назначения ключа. В D1 сохраняются только параметры доступа; подпись при необходимости вычисляется заново. Смена токена бота делает ранее выданные адреса недействительными.
- Публичный endpoint `/context-share/<id>.<signature>` принимает только GET/HEAD и отдаёт Markdown как `text/plain`, без скриптов и внешних ресурсов. Приватные операции создания, списка и отзыва требуют проверенной Telegram Mini App авторизации.
- Лимит хранения текста (30 дней) действует и для ссылок. Ссылка не даёт старую историю Telegram, вложения или доступ ко всему аккаунту.
- Агент должен уметь открывать веб-ссылки. Если такой возможности у него нет, использовать копирование текста или скачивание `.md`.

## Миграция и проверка

Таблица ссылок создаётся миграцией `cloudflare-worker/chat-migrations/0002_create_context_shares.sql` только в `CHAT_CONTEXT_DB`. Миграции `TASKS_DB` не применяются к базе контекста.

Для локального предпросмотра интерфейса доступен `/context/?demo=1`. Это только вымышленные сообщения и недействительные адреса `example.invalid`, без запросов к приватным API и без записи в базу.
